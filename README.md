# טיפות – Eye drops reminder

אפליקציית אנדרואיד לתזכורת טיפות עיניים אחרי ניתוח קטרקט.
התראה בכל מועד (קולית או שקטה), כפתור "בוצע" בתוך ההתראה, סימון לכל טיפה, עין אחת או שתיים.
כל דחיפה ל-main בונה APK ומפרסמת אותו ב-Releases.

The dosing plan lives in `app/src/main/java/com/tal/eyedrops/data/Plan.kt`.
